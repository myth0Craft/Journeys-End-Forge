## About the Mod
Journey's End is a progression based mod with the goal of creating a unique gameplay experience to overhaul the End dimension. While still in early beta, this mod will eventually include many custom biomes, custom bosses, new ore tiers, and dungeons to enhance the End dimension. Contains optional built in functionality with JEI for custom recipes. See LICENSE.txt for licensing details.

## Installation
1. Download mod jar file from [Modrinth](https://modrinth.com/mod/journeys-end-mod) or [Curseforge](https://www.curseforge.com/minecraft/mc-mods/journeys-end).
2. Create a new installation of Minecraft. Make sure the Minecraft version matches the mod version you downloaded. (Eg. if you downloaded a version of the mod for 1.21.1, ensure your Minecraft installation is also on version 1.21.1.)
3. Ensure Forge 52+ is installed in your new Minecraft installation.
4. Move the mod jar file into the "mods" folder of your Minecraft installation.
5. You are now ready to play, all you have to do is run the new Minecraft instance!

## Current Features
- An updated progression to how Eyes of Ender are obtained, making them much more difficult to get.
- A new dungeon containing the Endersent miniboss.
- Many new decorative and functional blocks.
- A new armor/tool tier obtained in the End.
- A fully implemented custom guidebook detailing every feature in the mod.

## Beta Features

To explore upcoming content, download the latest beta version of the mod from Modrinth or Curseforge. Warning: Some beta content may be incomplete or buggy.
- The Shadow Tower, a massive new structure in the End ruled by a mysterious dark lord. Can you ascend to the tower's peak?
- Warded blocks, blocks that can only be mined with a Wardbreaker pickaxe.
- A new blockset called Shadow Stone.
- Many new functional blocks, including an end respawn anchor, levitator blocks, a new type of mob spawner, void lanterns, and even a block that emits a high-damage laser beam.
